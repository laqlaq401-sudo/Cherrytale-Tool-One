关于 ▸
版本
项目性质
本机运行的个人学习项目：通过协议逆向复现 Cherrytale 的通信与 任务流程，把每日重复操作（领取、扫荡、市集采买等）整理为 可勾选、可设定次数的任务。
执行逻辑
命令行 python main.py run … 与网页端共用同一套 任务执行代码；网页端是其图形界面。
数据来源
数据全部来自游戏官方网关的只读接口 （角色与资源、主线进度、活动关卡、礼包列表等）； 登录与任务执行均使用你保存在本机的凭据，以你的账号身份进行。

安全与隐私 ▸

凭据与数据

  • 账号密码只在内存中使用一次，用于向官方服务换取令牌，随即丢弃—— 不写入文件、不进日志、不回显。
  • 网页端登录令牌仅保存在当前标签页的会话存储中，关闭标签页即失效； 换用其他浏览器或设备需重新登录。
  • 账号凭据保存在本机；会话被挤下线时，工具会用保存的凭据自动重新 登录并续跑当前任务。

网络边界

  • 服务默认只监听 127.0.0.1，仅本机可访问。 如需局域网访问，必须以 --host 0.0.0.0 --token 你的口令 启动，缺少口令时服务拒绝启动。
  • 服务不发送跨域响应头，并校验请求的 Host 与 Origin，拒绝非同源访问。
  • 同一时刻只允许一次运行；重复触发会排队等待，不并发发包。

行为边界

  • 默认只读：任务未设定次数时不发送消耗类请求。
  • 钻石消耗默认关闭：需先在「钻石使用」中打开总闸，且每个消耗型任务 单独确认；总闸关闭时不组装消耗类请求。
  • HTTP 层只重试 GET 请求；领取类请求一旦发出即不可撤销， 工具不提供强制中断。
  • 演练模式只组装并显示报文字节，不联网发送。
